# Raghav Sharma

I am working on ML systems and interpretability, with a bias toward protocols that make claims testable instead of just plausible.

The current thread is objective monitoring under model modification: when a model is fine-tuned, adapted, or otherwise changed, what evidence would actually show that an internal monitor is tracking the objective rather than memorizing lineage?

## Research

[A Protocol for Lineage-Invariant Objective Probing](https://github.com/Yatsuiii/lineage-invariant-objective-probing) - public preprint for a controlled experimental protocol testing whether objective-predictive internal probes transfer across modified model descendants without mostly learning lineage shortcuts. It is a protocol, not a results paper.

[BrainConnect-ASD](https://github.com/Yatsuiii/Brain-Connectivity-GCN) - adversarial graph neural network with a Gradient Reversal Layer for site deconfounding on ABIDE resting-state fMRI. Also included Qwen2.5-7B fine-tuning for ASD diagnostic report generation on AMD MI300X.
